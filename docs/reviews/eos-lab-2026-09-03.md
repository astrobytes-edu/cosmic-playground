## New findings

| ID | Severity | Status | Finding |
|---|---|---|---|
| EOS-1 | **P1** | **fixed** | `electronPressureFiniteTNonRelDynePerCm2` bracketed the degeneracy parameter η from a fixed start of 8, stepping `+4` to a hard cap of 240, while the zero-T shortcut only fired at `χ = T/T_F ≤ 1e-3`. The non-relativistic branch needs `η ∼ 1/χ`, so for `1e-3 < χ ≲ 4.2e-3` the bracket could not reach the root: `solveBisection` returned `NaN`, which propagated through `totalPressureDynePerCm2` → every pressure fraction → `classifyDominantPressure` → the regime map. Measured at **39 grid points** across the slider domain. The bracket is now seeded from `E_F/(k_B T)` and expands geometrically. |
| EOS-2 | **P1** | **fixed** | The demo's log-axis guard was `Math.max(1e-30, value)` — and `Math.max(1e-30, NaN)` is `NaN`. It floored nothing, so EOS-1's NaN reached a uPlot `distr: 3` axis, whose split lookup throws `RangeError`. Replaced with `logSafe()`, which handles the non-finite case explicitly. |
| EOS-3 | P2 | **fixed** | `latexScientific(NaN)` returned `"0"`, so the deep-dive equations positively asserted `P_deg = 0` where the model had failed. An existing unit test asserted this behaviour, locking the defect in; both are corrected. |
| EOS-4 | P3 | open | `solveBisection`'s `converged` flag is false for every successful solve and is then discarded — dead validation. |
| EOS-5 | P3 | open | `adiabaticIndex`'s docstring calls the pressure-weighted average "the standard stellar structure approximation"; it is ~6% off Chandrasekhar's Γ₁ at β = 0.5. |

No SI leakage: consistently CGS throughout.
