# Cosmic Playground invariants (shared by every cosmic-* skill)

Read this once per task. Skills link here instead of repeating it; if a fact below changes, change it
here only. CLAUDE.md is the project-wide source of truth; this file is the short form.

## Base path (GitHub Pages serves the site under /cosmic-playground/)

| Surface | Internal links and assets |
|---|---|
| Astro pages, layouts, components (`apps/site/src/**`) | Build from `import.meta.env.BASE_URL` (copy `withBase()` from `apps/site/src/layouts/Layout.astro`). |
| Markdown content (`apps/site/src/content/**`) | Relative links from the rendered page, e.g. `../../play/<slug>/`. `BASE_URL` is unavailable here. |
| Vite demos (`apps/demos/src/demos/**`, served at `/play/<slug>/`) | `../../explore/` or `new URL("../../", location.href)`. Vite `BASE_URL` is `./`, not the site root. |
| Playwright | `baseURL` + relative paths; never `page.goto("/explore/")`. |

Never write root-absolute internal links (`href="/..."`, `](/...)`) or the literal `/cosmic-playground/`.
Check: `node .agents/skills/cosmic-site-content/scripts/check-basepath.mjs`.

## Static site

`apps/site` builds with `output: "static"`. Query parameters never reach a server, so anything that
filters or sorts by URL must run in the browser (see `apps/site/src/lib/exploreFilter.ts`).

## Math: KaTeX, never Unicode

- Every reader-visible equation, symbol, unit and operator is LaTeX rendered by KaTeX. No `°`, `×`,
  `−`, `θ`, `M☉`, superscript digits — and no `\uXXXX` escapes that produce them (the validator
  cannot see escapes). Write `$L/L_{\odot}$`, `$10^{n}$`; never `e` notation in teaching copy.
- Canvas 2D / uPlot tick labels are the only exemption, and use ASCII (`lambda`, `deg`, `M_sun`).
- Markdown bodies are typeset at build (remark-math + rehype-katex). Display math is **fenced**:
  `$$` alone on the line above and below. Single-line `$$...$$` renders INLINE; the build rejects it.
- Frontmatter and `.astro` pages use client auto-render (`KatexAutoRender`), where `$$` is display.
- TS that emits reader-visible math: `renderInlineMath()` (site) or `renderMath()` (`@cosmic/runtime`).
- Enforced by `node scripts/validate-math-formatting.mjs` (runs in `lint` and `build`).

## Units and notation

- Units in variable names (`distanceKm`, `tiltDeg`, `thetaRad`) and on every label, readout and export.
- CGS for astrophysics; AU / yr / M_sun for orbits with `G = 4 pi^2 AU^3 / (yr^2 M_sun)`. Never `G = 1`
  or "natural units".
- `D` = physical diameter, `d` = distance. Never reuse either for anything else.

## Architecture boundaries

- Physics lives in `packages/physics` (`@cosmic/physics`). Demo code calls models; it never re-derives
  equations. Pure UI logic goes in each demo's `logic.ts` (tested); `main.ts` is thin DOM wiring.
- Shared demo behaviour lives in `packages/runtime` (`@cosmic/runtime`); no per-demo forks.
- Tokens, layers, shell and components live in `packages/theme`; no color literals in demo CSS.
- `packages/ui` exists but nothing imports it, and there is no renderer package.

## Things that do not move

- Legacy demos in `~/Teaching/astr101-sp26/demos/` are read-only (used in teaching this semester).
- `apps/site/public/play/` is generated by `corepack pnpm build`; never edit it by hand.
- Commits end with `Co-Authored-By: <model> <noreply@anthropic.com>` (or the agent's equivalent);
  stage explicit paths, never `git add -A`, and never stage a local `.gitignore` edit.
